# Antonio Bowden — Portfolio

Senior Network & Security Engineer in Orlando, FL.

Single-file portfolio website (`index.html`) for Network / Security Engineer roles at healthcare systems, credit unions, and MSPs. Built with a dark navy / gold design, covering skills, certifications in progress, experience, selected work, and on-site photos.

## Publish with GitHub Pages

1. Go to Settings → Pages in this repository.
2. Under "Build and deployment", set Source to "Deploy from a branch".
3. Set Branch to `main` and Folder to `/ (root)`, then Save.

The site will then be live at:

https://abowden101.github.io/antonio-bowden-portfolio/

## Local preview

Open `index.html` in a browser. No build step is required.
